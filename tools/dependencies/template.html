Import cycles and reference cycles differ. Scenes can name other scenes inside functions without importing them. source/main.lua loads those scene files before the functions run. Their references can form a cycle even when their imports do not.

What this chart measures

Generated from the current source/**/*.lua files. Comments and strings are excluded. Self-references are omitted. Local aliases still contribute a dependency at their assignment—for example, local datastore = playdate.datastore.

Solid arrows are named references, not imports. Each reference lists whether its file also directly imports the target. “No direct import” is not automatically an error: another file may load it first. Playdate is an external node; Lua built-ins and globals supplied by CoreLibs are outside this project-module chart.

Passed objects and callbacks are not resolved by this scan. For example, SceneManager receives a scene and calls currentScene.update(). It does not name FirstPersonScene, so that dispatch is absent here. Likewise, main.lua wires SystemMenu.refresh into SceneManager.onSwitch. This chart shows named coupling, not every possible runtime call.

Rebuild with python3 tools/dependencies/build.py. Source listings and line numbers are embedded; no network libraries required.
