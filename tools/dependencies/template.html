Scope: the game source was audited for direct assignments, nested writes, aliases, and mutation through passed or returned references. The six confirmed outside-write relationships shown here use owner operations. Raycaster, Hum, Compass, action mappers, and Slime trajectories return fresh results by default. Their hot-loop consumers explicitly supply private buffers; reusing a buffer overwrites its nested entries. This is a source audit, not a static proof against every possible future caller.

Constructors such as DockTimer.new() and Bob.new(), constant reads, ordinary function calls, and independently owned SDK objects are excluded. The earlier scene-reference cycles are not counted as ownership violations.

How this is built

Ownership findings are manually traced and backed by source anchors checked during generation. The lexical reference scanner alone cannot establish ownership, resolve object aliases, or detect escaped scratch buffers. Construction within an owner (including Run subclasses) and owner-managed records are legitimate writes. Puzzle constructors take ownership of fresh lists; save loaders take ownership of newly decoded datastore tables. Game, Maze, Puzzle, and MapDesign exports detach their nested save tables from live state. SoundBook notes, Shades patterns, and editor tool descriptors are immutable borrowed data. Puzzle item selectors and editor/scene design selectors intentionally return live objects. PlayInput.read returns its explicitly updated reader instance. Private renderer caches and SDK objects remain internal. Rendering, audio, and input consumers own their calculation buffers; MazeView sorts its own sprite records, and Game shuffles a newly returned free-cell list. SDK callbacks are explicit configuration, and SDK resources keep their own mutable APIs.

The background graph scans source/**/*.lua, excluding comments, strings, and self-references. Local aliases contribute references at their assignments. Passed instances and callbacks are not resolved. SDK and Lua built-ins are not individually audited here.

Rebuild with python3 tools/dependencies/build.py. Source listings and line numbers are embedded; no network libraries required.
